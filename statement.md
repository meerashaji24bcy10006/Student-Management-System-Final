# Student Management System

## 1. Problem Statement

Managing student information manually can be time-consuming and may lead to errors in storing, updating, and retrieving student records. The Student Management System provides a simple Java-based solution to manage student details and academic results efficiently.

## 2. Scope

The system is designed to manage student records and their academic results. It supports adding, viewing, searching, updating, and deleting student information. It also provides result calculation and file-based storage.

## 3. Target Users

- Students
- Faculty members
- Academic staff
- Educational institutions

## 4. High-Level Features

- Add student details
- View student records
- Search students using Student ID
- Update student information
- Delete student records
- Add academic results
- Calculate total, average, and grade
- Validate student information and marks
- Save student data using file storage
- Load saved student data when the program starts
- Handle invalid user input
